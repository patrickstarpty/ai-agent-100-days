## 决策记录模板

每个跨模块、难以回头的决定写一份。一页以内。

```markdown
# 决策 NNN：标题（用一句话写出决定本身）

- 状态：提议 / 已接受 / 已被取代（被哪一份取代）
- 日期：
- 相关课程：DayNN

## 背景

遇到了什么问题，有哪些约束。只写与这个决定有关的事实。

## 决定

我们决定……。写成可以被检验的陈述，避免“尽量”“适当”这类词。

## 考虑过的方案

| 方案 | 优点 | 没有采用的原因 |
| --- | --- | --- |
| | | |

## 后果

- 这个决定让什么变容易了。
- 这个决定让什么变难了，或者引入了什么新的约束。
- 什么情况出现时应当重新评估这个决定。
```

### 写的时候检查三件事

1. 只看“决定”一节，读者能否知道该怎么做？
2. “考虑过的方案”里，有没有把真正纠结过的那个方案写进去？
3. “后果”里有没有写出代价？只有好处的决策记录通常是没想清楚。
