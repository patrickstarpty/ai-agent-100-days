## Day76 - 阶段复盘：技术栈映射

> 可观测性与生产化 ｜ 建议用时 1 小时，无新材料

> **一句话**：把参考实现和目标技术栈之间的每一处差异都写下来，并各做一个决定。
>
> **放在全局看**：这是第四份阶段文档，评审清单在这里加上“权限与平台底座”一节。

### 学习目标

把参考实现迁到目标技术栈（本课程以 Azure Foundry + LangGraph + Langfuse 为例）时的全部差异收进一份文档。

### 产出一：技术栈映射表

完成 [技术栈映射表](../模板/技术栈映射表.md)。每一行回答：参考实现用什么、目标栈用什么、差异是什么、决定是什么、理由是什么。至少包含：

- 模型入口（Day70）
- 追踪与评估后端（Day69）
- 部署形态（Day73）
- 检索与权限（Day21）
- 任务队列与持久化（Day72）

### 产出二：评审清单的“权限与平台底座”一节

打开 [设计评审清单](../模板/设计评审清单.md)，补充：

- 模型调用是否只有一条路径？
- 追踪用的是开放标准还是某个平台的私有埋点？
- 每个 agent 的运行身份是什么，权限范围多大？
- 检索是否按提问人过滤，派生物是否继承权限？
- 追踪数据有没有保留期，谁能看到其中的原文？

### 阶段验收

- [ ] 参考实现的每个组件都能在目标栈里找到对应，每处差异有决策记录。
- [ ] 一次真实对话的完整追踪能在 Langfuse 里看到，包含检索、模型调用和工具调用。
- [ ] 能从一条回答追溯到当时实际使用的模型和 token 用量。
