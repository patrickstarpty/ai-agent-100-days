## 学习资源汇总

课程各阶段引用的外部材料。每个链接在写入课程时都打开核对过；技术文档更新很快，使用前请以原站当前内容为准。

### 大模型应用基础与编排思路

- 吴恩达 [Agentic AI](https://www.deeplearning.ai/courses/agentic-ai/)：DeepLearning.AI 的视频课程，5 个模块，约 10 小时，可免费旁听。讲反思、工具使用、规划、多 agent 四种设计模式，以及评估和错误分析。推荐作为本课程的视频补充。
- [Building effective agents](https://www.anthropic.com/engineering/building-effective-agents)：工作流与 agent 的区分，五种工作流模式。
- [Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)：压缩、结构化笔记、子 agent、即时检索。
- [12-Factor Agents](https://github.com/humanlayer/12-factor-agents)：构建可靠 agent 应用的十二条原则。
- [LiteLLM 文档](https://docs.litellm.ai/docs/)：Day01~10 示例代码使用的调用库。
- [Prompt engineering overview](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview)：提示词写法的系统说明。

### 知识检索

- [Introducing Contextual Retrieval](https://www.anthropic.com/engineering/contextual-retrieval)：上下文化的向量与关键词索引，加重排。
- aider [Repository map](https://aider.chat/docs/repomap.html)：给模型一份全仓库的符号地图。
- Microsoft Learn [Document-level access control in Azure AI Search](https://learn.microsoft.com/en-us/azure/search/search-document-level-access-overview)：文档级权限的几种实现方式。
- Microsoft Learn [Connect agents to Foundry IQ knowledge bases](https://learn.microsoft.com/azure/ai-foundry/agents/how-to/tools/knowledge-retrieval)：agent 通过 MCP 接入知识库，以及按用户过滤。

### 评估

- [Demystifying evals for AI agents](https://anthropic.com/engineering/demystifying-evals-for-ai-agents)：评分器类型、能力评估与回归评估、从零建评估的步骤。
- [AI Evals FAQ](https://hamel.dev/blog/posts/evals-faq/)：错误分析、二元标注、评审员校准。
- Langfuse [评估总览](https://langfuse.com/docs/evaluation/overview)、[Datasets](https://langfuse.com/docs/evaluation/experiments/datasets)、[LLM-as-a-Judge](https://langfuse.com/docs/evaluation/evaluation-methods/llm-as-a-judge)、[Experiments in CI/CD](https://langfuse.com/docs/evaluation/experiments/experiments-ci-cd)
