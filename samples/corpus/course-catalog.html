三个课程小组都隶属于教务组。

Python 入门

从变量、条件和循环讲起，到函数、模块、文件读写和异常处理。每个课时配一组练习题，可以在练习空间里直接运行。适合没有编程经验的学员。

数据分析实战

用表格数据完成清洗、汇总、分组统计和图表制作，最后完成一个分析小项目。需要先学完 Python 入门。

Web 开发基础

讲解请求与响应、路由、模板、表单和简单的数据存储，最后部署一个留言板小应用。需要先学完 Python 入门。目前只包含在团队套餐里。

学习顺序建议

先学 Python 入门，再根据方向选择数据分析实战或 Web 开发基础。两门中级课程之间没有先后要求。
